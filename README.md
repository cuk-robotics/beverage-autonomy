# Beverage SmolVLA

SO-101 양팔 음료 제조 프로젝트의 **학습·평가·실물 추론 코드를 통합할 저장소**입니다.

> 초기 구성 단계입니다. 현재는 저장소 역할과 이전 기준을 정의했으며, 실행 코드 이전 및 이 저장소에서의 학습·실물 검증은 아직 완료하지 않았습니다.

## 저장소 역할

| 저장소 | 역할 |
| --- | --- |
| [smolvla-bimanual-manipulation](https://github.com/cuk-robotics/smolvla-bimanual-manipulation) | 데이터 수집 기준: 장치 설정, 보정 연결, 원격조작, 연습, 기록 및 수집 품질 확인 |
| **beverage-smolvla** | 최종 통합 대상: 학습 설정, 정책 평가, 추론 실행, 실험 재현 및 결과 문서 |
| [.github](https://github.com/cuk-robotics/.github) | 조직 소개 및 공통 GitHub 구성 |

기존 저장소에는 추론 코드와 학습 실행 도우미도 있습니다. 코드 이전 검증 전까지 기존 실행 경로를 유지하며, 이 문서는 기존 기능을 제거했다는 의미가 아닙니다.

## 통합 원칙

- 로봇 제어·기록·학습·정책 rollout은 설치된 공식 LeRobot에 위임합니다. site-packages 수정이나 upstream 소스 복제를 하지 않습니다.
- 동일 기능을 두 저장소에서 각각 수정하지 않도록, 이전 시 기능별 관리 저장소와 기준 commit을 명시합니다. 공통 장치·관측 계약은 버전으로 관리합니다.
- 데이터와 모델은 Hugging Face의 repo_id와 정확한 revision으로 연결합니다. 원본 데이터·영상·모델 가중치는 GitHub에 넣지 않습니다.
- COM 포트, 카메라 인덱스, 보정 파일, 인증정보, PC 경로는 로컬에서 관리하고 공개 설정은 예시만 제공합니다.
- 자동 Hub 업로드는 기본 비활성화합니다. 보정·관절 순서·단위·정규화·목표 제한을 근거 없이 변경하지 않습니다.

## 코드 이전 순서

1. 기존 로컬 변경과 원격 commit의 차이를 확인하고 이전 파일 목록·출처 commit·파일 해시를 기록합니다. 미커밋 코드를 원격 최신본으로 간주하지 않습니다.
2. 데이터 계약을 확정합니다: state/action 이름·순서·단위·차원, 카메라 키·해상도·FPS, 작업 문장, 보정/제어 조건. 실제 데이터 메타데이터와 설치 장치 코드로 확인합니다.
3. 학습 실행 도우미·정책 feature 검사·추론 실행기와 필요한 의존 모듈·오프라인 검사를 선별 이전합니다. 통합 CLI의 일부 파일만 복사하지 않습니다.
4. 학습 설정과 데이터 분할을 재현 가능하게 만듭니다. 원본과 병합본에 같은 시연이 중복 포함되므로 원본 세션/에피소드 기준으로 train/validation/test 누수를 방지합니다.
5. 장치 없는 설정 검사와 단위 검사를 통과한 뒤 저장 관측 기반 추론을 확인합니다. 실제 모터 구동과 성공률 평가는 별도 절차로 수행합니다.
6. 검증된 학습·추론 코드를 이 저장소의 기준으로 지정하고 기존 저장소는 수집 기준으로 유지합니다.

## 예정 구조

아래는 코드 이전 시 적용할 구조이며 현재 구현 목록이 아닙니다.

```text
configs/      # 공개 학습·평가·추론 설정 예시, 데이터/모델 revision 목록
scripts/      # 공식 LeRobot 실행 진입점과 오프라인 검사
src/          # 프로젝트 고유 설정·데이터 계약 검증·실행 연결
tests/        # 장치 없는 검사
docs/         # 환경 재현, 데이터 계약, 평가 기준, 실물 실행 절차
```

## 재현 및 평가 기준

각 실험에 코드 commit, 패키지 버전, 데이터/모델 revision, 분할 목록, seed, 학습 설정 및 체크포인트를 기록합니다. 장치 설정과 보정의 식별 정보는 필요한 범위에서 로컬 실험 기록에 보관합니다.

오프라인 loss와 실물 성공률을 구분합니다. 실물 평가에는 작업별 성공/실패 기준, 시도 수, 초기 배치, 수행 시간, 사람 개입 및 중단 여부를 기록합니다. 음성인식·자동 단계 전환·완료 판정은 구현과 검증 전까지 완료 기능으로 표시하지 않습니다.
